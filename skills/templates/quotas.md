> 当 aiwriter.md 主流程走到 Step 4 自检 ② 或 Step 6 第二刀（AI 味刀）时 Read 此文件。
> **本文件是 AI 味相关黑名单/配额的唯一权威版本**——`aiwriter-review.md` 不再维护副本，直接 Read 本文件；Workflow `aiwriter-review` 的 AI味刀代理同样 Read 本文件全文，改这里即生效，不用改工作流脚本。
>
> 三层递进（配额比扫词更重要，但三层缺一不可）：
> - **AI 味 1.0**：段落/全文级配额 + 段首路标词（本页第 1-3 节，管"多不多"）
> - **AI 味 2.0**：段落级病征扫描（本页第 4 节，管"像不像 AI 复读机"）
> - **AI 味 3.0**：句法层 + A 类结构病征（本页第 5-6 节，管"AI 中文语病"和"抽象论点拆解型模板"——**新增，覆盖了前两层管不到的病灶**）

## 硬配额表（跨全文累计，超标即修）

| 配额项 | 精炼版 | 标准版 | 深度版 | 超支处理 |
|------|------|------|------|---------|
| 加粗独立成段 | ≤ 2 | ≤ 3 | ≤ 4 | 保留最锋利的 |
| 一句话成段 | ≤ 2 | ≤ 4 | ≤ 6 | 合并回正常段落 |
| 段首路标词 | = 0 | = 0 | = 0 | 全部删除 |
| 金句加粗 | ≤ 2 | ≤ 3 | ≤ 4 | 同加粗独立成段 |

**金句配额与加粗配额对齐**：两者是同一件事的两个视角。

**"不是 A，而是 B" 骨架句——不是硬计数配额，是逐条质量判断**（真实回归测试发现：干净文章可以合理用到 9 次，而 AI 味最重的样本反而刻意规避了逗号连写的"不是…而是…"，改用"不是X。是Y。"拆成两句 + 加引号来躲检测——纯计数配额会两头出错，既误伤好文章又漏抓变体）：

对每处命中（含变体："不是A，而是B"／"不是A。是B。"跨句拆分／引号包裹规避），逐条问：**这一处是否引入了新的具体信息（新判断/新对象/新证据），还是只是把同一个抽象标签换个说法重复一遍？**
- **有新信息**（如"不是被当作负责任的人使用，而是被当作齿轮、杠杆和连杆"——具体到了"齿轮/杠杆/连杆"）→ 保留，不限次数
- **空转标签互换**（如"不是某个 leader 在欺负你。是整个组织的能力定价机制变了。"——两边都是抽象概念，没有新增可核实的具体内容）→ 改直陈句，删掉这个骨架
- 一节内空转命中 ≥3 处 → 该节判定为"清单的清单"同类病征，触发整节重写（见下方 A 类结构病征）

## 比喻质量测试（无数量上限，每个过两关）

- **陈腐测试**：这个比喻在过去一年内被 ≥3 篇爆款用过吗？
  - 已知陈腐清单（发现即禁用）：光纤泡沫 / 种树 / iPhone 时刻 / 元年 / 寒武纪 / 蒸汽机时刻 / 移动互联网前夜 / 工业革命级 / 基建期
  - 禁用后换具体事实直接说
- **替代测试**：把这个比喻删掉，用具体事实直接说，哪个更清楚？
  - 更清楚 → 比喻是多余的，删
  - 过两关 → 随便用

## 段首路标词黑名单（发现即删，用内容逻辑过渡替代）

- "注意" / "问题来了" / "翻译成人话" / "画风突变" / "你读到这里"
- "让我们来看" / "接下来" / "下面我们谈谈" / "首先 / 其次 / 最后"
- "有意思的是" / "值得一提" / "不难发现" / "不得不说" / "值得注意"
- "总的来说" / "综上所述" / "说到底"（出现在段末也要改）
- "写到这里" / "话又说回来" / "回到主线"
- "想必你已经发现" / "聪明的读者会问"

## AI 味 2.0 特征扫描（发现即改）

- **比喻通货膨胀**：同一段出现 ≥2 个比喻 → 删到 1 个或 0 个
- **段首指路成瘾**：任何段以路标词开头 → 删路标词，用内容逻辑过渡
- **加粗金句滥发**：相邻 3 段内 ≥2 处加粗 → 删到 1 处
- **"亲切口语"伪装**：识别"你读到这里应该意识到了"、"翻译成人话"、"画风突变"这类假亲切 → 删除或换说法
- **均质段落**：连续 3 段以上长度和语气相似 → 打散 1 段（短句/反问/具体场景）
- **形容词堆砌**："极为重要"、"非常关键"、"尤为突出" → 改为具体事实或删
- **排比式宣言**："不是 X，而是 Y；不是 Z，而是 W" 连续 3 句以上堆叠 → 保留最锋利的一组（注意：单次或分散使用不算——判断标准见上表"不是A而是B骨架句"的质量判断，不是数数）

**配额比"扫词"更重要**——即使每个词都不违规，如果全文 5 个比喻、6 处加粗，照样是 AI 味重灾区。

## AI 味 3.0 · 句法层扫描（借自 `/writing` 教练 skill 的中文质量诊断表）

> 前两层管的是"词/段"，这一层管的是**句子内部的语病**——AI 中文最典型也最容易被忽视的病征。逐句过一遍，命中即改，不是全文只抽查几句。

| 类型 | 特征 | 严重度 | 改法 |
|------|------|--------|------|
| 的字链过长 | 一句中连续 3+ 个"的" | 中 | 拆成两句或改动词结构 |
| 被动语态直译 | "被…所…"、"被认为是" | 中 | 改主动句 |
| 介词堆砌 | "关于…对于…在…方面" | 高 | 去掉介词框架，直接说 |
| 名词化堆砌 | "进行了…的操作"（应直接用动词） | 中 | 动词直给 |
| 欧化长句 | 一句 60+ 字，嵌套从句 | 高 | 拆成 2-3 句 |
| 过度使用连接词 | 然而/但是/因此/所以 每段 3+ 个 | 低 | 删多余连接词，靠逻辑顺序过渡 |
| 翻译腔 | 直接照搬英文句式结构（如"这不是一个 X 的问题，而是一个 Y 的问题"套壳） | 高 | 换成中文母语者会说的话 |
| 模糊限定词泛滥 | 很多/一些/某种程度上/可能/似乎/基本上，一段内 ≥2 处 | 低 | 换成具体判断或具体数字 |
| 空洞大词 | 进行/实现/开展/推动/促进（有更具体动词可用时） | 低 | 换具体动词 |

## AI 味 3.0 · A 类结构病征扫描（「抽象论点拆解型」文章高发，发现即改）

> 诊断样本：`posts/2026-06-26/ai-not-kill-but-reprice-middle-managers/article.md`——AI 味不是均匀分布的，几乎全部集中在"讲抽象论点"而非"讲具体的事"的文章里。以下 6 条专打这一类。

| 病征 | 判断标准 | 修复 |
|------|---------|------|
| **自造抽象二分框架** | 文章靠一组自造术语撑起论证（如"功能层 vs 角色层"），术语在业内并无通行定义 | 换成挂靠具体事件/案例的论证，或明确标注"这是本文自定义的说法" |
| **无来源精确数字** | 出现"80%"、"3-5 倍"、"18 个月"这类看似精确却查无来源的数字 | 挂具名来源；查不到来源就改成"约一半"式模糊量级，并标注"估算"（这一层和 Step 6 第五刀「事实刀」互补：事实刀核对已写数字是否属实，本条拦的是写作时编造精确度的习惯） |
| **"不是 A，是 B"空转堆叠** | 同一节内该骨架句（含跨句拆分变体）**空转**（不引入新具体信息，见上方硬配额表的质量判断）出现 ≥3 处 | 逐条判断，空转的改直陈句，有新信息的保留 |
| **清单的清单** | 一节内加粗小标题+短句+列表/表格的密度过高，找不到 1 段 ≥3 句的连续散文 | 至少改回 1 段连续散文，把列表内容还原成叙述 |
| **口头禅换气** | 同一过渡口头禅（如"兄弟们……想清楚——"）在全文重复 ≥2 次 | 删到最多 1 次，其余换成内容逻辑过渡 |
| **意义封装套话** | "这才是……真正的……"、"这就是……的含义"、"最该让人后背发凉的" 这类"我要宣布一个深刻结论了"的仪式性铺垫 | 删掉铺垫，让结论自己成立，不需要被宣布 |

**触发规则**：命中以上任意 2 条即视为落入 A 类模板，触发**整节重写**（不是局部改词）。
